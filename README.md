# MediFind: Smart Pharmacy Inventory System

Plain PHP + MySQL scaffold for XAMPP localhost.

## Setup

1. Copy or keep this folder inside your XAMPP `htdocs` directory.
2. Start Apache and MySQL from XAMPP Control Panel.
3. Import `database/medifind.sql` using phpMyAdmin.
4. Open `http://localhost/MediFind/`.

## Seed Logins

- Admin: `admin@medifind.local` / `password`
- User example: `aarav.sharma@example.com` / `password`
- Pharmacy example: `careplus.andheri@medifind.local` / `password`
